### After two months of rebuilding the architecture and developing the project, I can announce the release of V2.0. **What’s new:**

1. **The use of Rust for drawing the graphical interface.** Thanks to the use of this particular programming language, **the application’s weight and RAM usage are very low.**

2. **Extension masking as a separate innovation.** Previously, in the console version, it was possible to change the extension, but it worked a bit differently (for example, you could take an exe and make it a zip); **now it works as a separate, full‑fledged function that fully masks the extension.**

3. **Simplified usage.** Previously, to use the program, you had to first compile it, then place it in a folder and add it to the Path variable, and only then could you use it; **now everything is rendered in a simple GUI that works right out of the box.**

4. **Added MultiLanguage support.** In addition to English, **German**, **Russian**, and **Spanish** have also been added.
